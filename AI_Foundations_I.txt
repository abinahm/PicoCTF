Important part to understand:
1. Output rule: w1*x + w2*y + b >= 0 -> 1, else 0.
2. Goal: make the last 8 outputs read 01110000 (ASCII 'p').

Basic math would teach us that anything multiplied by 0 is well... 0, and anything mutiplied by a negative number would automatically be negative, unless the number itself is negative.

Assuming w1 and w2 are >= 0, the zeroes of the output can be determined by using zeroes and negative numbers. 

Anything more than zeros would be a positive number and return the output 1.
